# 萌可成长星球

面向 5 岁幼升小儿童的学习与陪伴工作台，适配电脑、PAD 和手机。项目已经按公网部署和桌面安装准备，兼容 Netlify 和 Vercel。

本地预览可以双击 `打开工作台.bat`。公网发布后，家长只需用浏览器打开网址，再点“安装到桌面”即可。

## 已包含

- 今日日期、山东参考天气与可选定位实时天气
- 每日计划打卡：英语磨耳朵、拼音听写、数学小游戏、识字、自己收拾书包
- 拼音听辨与温柔慢速示范，拼音语速固定为 0.8
- 20 个常用汉字认读、示例词语、句子朗读和在线书写练习
- 日常英语短语、听音选图和单词发音
- 10 以内与 20 以内数学自主答题，包含点数、加减法和图形提示
- 萌可电子宠物：饱饱、香香、开心三项状态，可喂食、洗澡、玩耍和换装
- 温柔陪伴对话，支持快捷话题、文字输入和浏览器语音输入
- 七日成长统计、能力进度、连续天数和给家长的观察建议
- 本机自动保存，并用随机匿名编号同步到 Netlify 后台，统计页实时显示同步状态
- 每晚 0 点自动刷新每日任务、故事、冷笑话、识字、拼音和英语推荐
- 每天一个 5～10 分钟原创故事、每日冷笑话和细心观察小游戏
- 多轮语境陪聊：记住最近对话、情绪和话题，支持自然追问与切换话题
- PWA 桌面安装与离线缓存

## 使用说明

推荐使用最新版 Microsoft Edge 或 Chrome。朗读使用设备自带语音，实际音色会随系统语音包不同而变化；如果声音不明显，可以在系统设置中安装中文语音包。

天气默认显示山东参考信息。点击天气卡片后可授权定位以获取当前位置天气，不授权也不影响其他功能。实时天气需要联网。

学习记录会在浏览器保存，并通过随机匿名编号同步到 Netlify Blobs。聊天记录不会上传到进度后台。清空记录可在“成长记录 → 家长设置”中操作。

## 公网发布

项目同时包含 Netlify Function `netlify/functions/chat.js` 和 Vercel Serverless 接口 `api/chat.js`，支持 DeepSeek、豆包（火山方舟）和 OpenAI。只选择一家配置即可：

- DeepSeek：配置 `DEEPSEEK_API_KEY`，默认模型为 `deepseek-chat`。
- 豆包：配置 `DOUBAO_API_KEY` 和 `DOUBAO_MODEL`。
- OpenAI：配置 `OPENAI_API_KEY`，默认模型为 `gpt-4.1-mini`。

所有密钥只放在云端服务端，绝不能写进前端文件。

完整步骤见 `DEPLOY.md`。Netlify 必须通过 Git 仓库进行带 Functions 的发布，单纯拖拽静态文件不会部署陪聊接口。没有配置云端模型时，聊天会自动使用改进后的本地上下文回应；配置成功后，标题旁会显示“智能陪伴 · 已连接”。

## 内容与安全说明

学习内容按一年级入学常见能力顺序编排：拼音启蒙、常用字识读、20 以内数感、日常英语和生活习惯。山东各地学校使用的教材版本可能不同，因此这里提供原创练习内容，不复制或冒充某一套统一教材，具体教学进度以学校为准。

智能陪聊开启时，最近对话会通过本站 Cloud Function 发送给所配置的模型服务生成回复，接口不保存对话，也不会把密钥发送到浏览器。它不是心理医疗工具；涉及受伤、欺负、危险或让人不舒服的秘密时，界面会明确鼓励孩子立刻告诉信任的大人。
